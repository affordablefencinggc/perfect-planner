## Conflict/ownership rules

### Native transport constraints established during Work272

Do not start an ordinary Node named-pipe listener and call it owner-only. Windows'
default named-pipe security descriptor can allow Everyone/anonymous read access:
https://learn.microsoft.com/en-us/windows/win32/ipc/named-pipe-security-and-access-rights

The native endpoint must explicitly set a protected DACL for the current owner,
reject remote clients, prevent pipe-name squatting, and bound message sizes,
connections and deadlines. Separate native-owner operations (issue pairing/revoke)
from client operations (connect/heartbeat/read/propose); possession of a normal
session must never access owner operations. Authenticate both endpoints before
sending pairing material. Verify these properties on DANS1 before exposing tools.
