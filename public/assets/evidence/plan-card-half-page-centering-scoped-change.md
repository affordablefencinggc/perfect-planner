# Plan-card half-page centering

- The plan canvas now spans the available page width instead of using a narrow fixed-width strip.
- Each plan row uses a left region, fixed centre-spine lane, and right region.
- A left card is centred between the page's left edge and the spine; a right card receives the exact mirrored position.
- Card width remains capped at the approved 552 px.
- Dashed connector reach is calculated from the live row width so it continues from each centred card to the fixed spine.
